# bobo_food

Bobo Food is a modern Flutter-based food delivery UI application that provides a complete user journey from onboarding and authentication to browsing meals, managing cart, and placing orders. It is designed as a clean, responsive, and reusable front-end structure suitable for building a full-featured restaurant or food delivery app.

# Key Features
- Full onboarding and authentication flow (sign in, sign up, OTP, forgot password)
- Home screen with banners, categories, search, and food listings
- Product details with ratings, calories, delivery time, and quantity control
- Explore screen for browsing food categories
- Cart management with price summary and item updates
- Coupon and discount application system
- Complete checkout flow with address and payment selection
- Order confirmation and tracking UI
- Favorites, My Orders, and Profile management
- Settings with theme, language, support, and account options
- Bottom navigation for smooth user experience
